Duplicate Data Cleaner

Automatically detect, review, and merge duplicate contacts, companies, and products — keeping your Odoo database clean and accurate.

Key Features

🔍 Smart Duplicate Detection

Three detection engines work together:

  • Email match — exact email address comparison (case-insensitive)
  • Phone match — normalised phone number comparison (strips formatting)
  • Name similarity — fuzzy Levenshtein-based matching with configurable threshold

🔀 One-Click Merge

Select the master record and merge with a single button press:

  • All related records (sales, invoices, purchases…) are re-linked to the master
  • Duplicate records are soft-archived (never deleted)
  • Full merge history is stored for audit and undo

📊 Dashboard & Statistics

  • KPI cards: pending groups, merged groups, ignored groups
  • Breakdown by model (Contacts vs Products)
  • Recent merge history at a glance
  • Scan button directly on the dashboard

⏮ Undo & Audit Trail

  • Every merge stores a full JSON snapshot of all field values
  • One-click undo: re-activates the archived duplicates
  • Audit log shows who merged what and when

⚙️ Automated Scheduled Scans

  • Built-in daily cron job (disabled by default, enable with one click)
  • Zero-configuration: just install and activate

🛡️ Safe & Non-Destructive

  • Records are archived, never permanently deleted
  • Confidence score helps prioritise which groups to review first
  • Ignore groups you don't want to merge

How It Works

  1. Install the module — no extra configuration needed.
  2. Go to Duplicate Cleaner → Dashboard and click Scan for Duplicates.
  3. The scanner checks all contacts and products for matching emails, phones, and similar names.
  4. Review each Duplicate Group — see all candidates side by side.
  5. Select the Master Record (the one to keep) and click Merge Selected.
  6. All FK references are re-linked automatically. Duplicates are archived. Done.
